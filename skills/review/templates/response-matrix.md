# Response matrix

One row per referee comment. You decide, before writing a single sentence of the letter, whether the comment is something you must fix or something you will argue with. The matrix is what stops the letter from becoming a list of apologies.

## How to use this file

Copy it to your project as `response-matrix.md`. Build it in the first hour after the decision arrives, from the referee report itself, while you are still irritated and therefore still reading carefully. Fill the first three columns immediately. Fill column four only after you have actually made the change, and column five last.

When the matrix is complete, the letter almost writes itself: each row becomes one block of the letter, in the same order.

## The five columns

| Column | What goes in it |
| --- | --- |
| Comment | The comment in your own words, one sentence. Quote the referee only if the wording decides the answer. |
| Must fix or argue | `fix`, `argue`, `fix and argue`, or `ask`. Use `ask` when the comment is unclear, and put the question in the letter. |
| Where the change lands | Section, page, table or figure number. Write `none` when you are arguing instead of changing. |
| What changed, in one line | The substance, not the gesture. Write “added 2001 to 2015 to the sample and reran columns 2 to 4”, not “addressed the sample period”. |
| Open | `done`, `drafted` or `unresolved`, so you can see at a glance what is left. |

## Worked example

| Comment | Must fix or argue | Where the change lands | What changed, in one line | Open |
| --- | --- | --- | --- | --- |
| The sample period is too short to capture the reform | fix | Section 3.1, page 9; Tables 2 and 3 | Extended the sample from 2001 to 2015, reran columns 2 to 4; the coefficient moves from 0.352 to 0.341 | done |
| The parallel-trends test is reported only in the text | fix | Figure 2, Appendix Table A3 | Moved the event study to Figure 2 and reported the pre-trend test with its p-value | done |
| Clustering at the firm level is too conservative | argue | Section 5.2, page 21 | Reported block and year clustering as well; standard errors range from 0.100 to 0.156 and the conclusion is unchanged | done |
| The paper should also study wages | argue | Section 1, page 2 | Added a sentence explaining that wages are measured at the city level while treatment is at the firm level, so the design cannot support that margin | done |
| The contribution relative to the closest paper is unclear | fix and argue | Section 1, page 3 and Section 6, page 27 | Added a paragraph naming the closest paper and the three differences, and removed the claim the referee says is not supported | done |

## What to do with each row

- `fix`: the referee is right. Change it, then write what changed.
- `argue`: the referee is wrong, but you need an argument with evidence in it, not an assertion. If you cannot write the argument in three sentences, it is probably a `fix`.
- `fix and argue`: change something and say why you stopped there.
- `ask`: write the question into the letter, in its own numbered item, and say what you will do under each reading.

A letter with no `argue` rows reads as though you have no judgement. A letter with mostly `argue` rows reads as though you have not read the report.

## What this file is not

It is not the letter, and it is not a place to keep comments you decided to ignore. Every row must end in `done`. A row that says `unresolved` at submission time is a comment you did not answer, and referees notice those.
